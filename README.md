# Nu Giz Wrap

This package is meant to assist in level modding for the Nu2 (PS2-HD) Lego games (TCS, LIJ1, LB1).
It has only been tested with Unity 6000.2.8f1, but may be compatible with other versions too.

## Gizmo File Support

Nu Giz Wrap is primarily focused on modding gizmos and allows importing and exporting.

GitHub Page: <https://github.com/Matthew6596/NuGizWrap>
